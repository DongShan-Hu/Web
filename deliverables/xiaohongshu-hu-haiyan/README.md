以普通潜在客户为读者，重点展示个人网站的气质、作品陈列、手机体验和定制入口。六图统一采用米白、水墨与朱红配色。胡海燕姓名按用户本轮确认保留；未加入未经确认的授权、成交、客户反馈或效果承诺。

## 图像制作说明

使用内置 imagegen，以最新本地网页的真实截图为参考，生成海报与设备展示图。设备和画面属于生成式合成，并非未经处理的逐像素原始截图；网页功能与细节以实际网站为准。书画素材由本人提供，一页映负责网页设计与制作。

在工作目录中，完整提示词保存在 `generation-prompts.json`，原始网页截图在 `references/`（这两项未放入发布压缩包），其中手机首页已包含本轮顺序调整，山水大图为真实八件画廊的第七件。

## 发布准备

文案不含外部网址、二维码、价格或虚构转化数据。配图采用本轮最新本地页面；此前前端修改尚未部署，若要分享网站链接展示最新效果，应先把更新同步到线上。此发布包未自动发布到小红书。
