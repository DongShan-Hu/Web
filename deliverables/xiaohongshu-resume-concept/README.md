# 一页映 · 小红书第三篇发布包

**主题：只有一份简历，也能做成这样。**

示例人物为虚构的“林悦”，方向为内容运营与项目执行；“城市读书计划”为虚构的社群主题活动项目。所有图片均标注 **「设计示意 · 非真实交付案例」**。

## 怎么使用

1. 按文件名前的数字顺序上传 `images/` 中的六张 PNG，统一为 1086 × 1448，图片比例为 3:4。
2. 使用 `01-cover.png` 作为封面。
3. 打开 `发布文案_直接复制.txt`，第一行用于标题，其余用于正文与标签。
4. 如需先检查图片，打开 `index.html`。预览支持手机宽度排版，点击图片可打开原图，也可直接复制文案。

## 图片与内容说明

- 六张图片使用内置 imagegen 工具生成宣传排版。屏幕画面以本地 HTML 示意页的实际截图作参考，细微小字可能有重绘；需要核对页面文字与布局时，以本地示意页为准。完整提示词保存在制作目录的 `generation-prompts.json`。
- 姓名、经历与项目均使用示例资料，不代表真实客户、真实交付或已上线网站。页面展示不承诺录用、求职或业务结果。
- 示例项目内容统一为：活动策划、内容排期、执行跟进；产出为活动方案、内容排期、复盘记录。
- 网页设计与制作：一页映。

## 制作目录补充

完整制作目录还保留 `demo/index.html`（响应式示意页）、`demo/resume.html`（同内容简历来源页）、`references/`（截图参考）及 `generation-prompts.json`（生成提示词）。示意页是本次图片的布局依据，未作为客户网站交付或上线。

发布 ZIP 仅包含六图、发布文案、发布顺序、预览页与本说明。制作源文件及截图参考不放入发布 ZIP；预览页本身无外部依赖，解压后保留原目录结构即可使用。
