## 检查与修复记录

1. 首轮发现 SVG 标识无法显示：预览服务器未声明 SVG MIME。增加 `image/svg+xml` 后重启本任务预览服务器；最终页面图片检查无缺失资源，HTTP HEAD 验证正确。
2. 首轮发现旧截图带大面积播放器黑边，使图片与说明失衡。改用内容区域的 CSS 展示裁切，并增加可点击原图缩略图；弹窗继续展示完整原始图片。最终 `v3-case-final.png` 与 `v3-vision-final.png` 已复核。
3. 官网若森旧素材实际是版式背景，不适合作独立标识。替换为核对过的企业资料 Logo；Nuke 完整字标在小尺寸下图形过小，替换成 Simple Icons 的图形版本；Maya 改为 Devicon 品牌图标。最终经历和技能截图均已复核。
4. 原技能只占半幅且默认折叠。改为 UE / Nuke 双列展开，Maya / Arnold / Redshift 次级技能行；手机为单列。主要技能正文15px，背景对比清楚，无百分比熟练度或虚构业绩。
