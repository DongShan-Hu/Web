# V3.1 字号检查与修正

2026-09-13。范围：现有作品集页面的屏幕阅读字号；不改作品内容、首页主标题、PDF 或打印排版。

## 检查步骤与发现

1. 正文与技能：原正文 15px，技能说明及链接 11–12px；桌面主次文字差距过大。正文现为 17px，手机 16px，说明及操作为 14px。
2. 图注、时间及项目标签：原手机端存在 8–11px 小字。图注现为 14px，辅助标签一般为 13px；手机公司日期和案例分类为 12px。保留首页非关键装饰性英文的小字号。
3. 案例选择与详情：手机三列标签改为纵排，不再依赖缩小字来容纳内容。弹窗正文为 16px，已确认打开后没有横向溢出。
4. 首页：保留主标题与图像构图，只放大介绍、职责日期、链接。320px 屏宽下修复了按钮中文断行。

## 当前结果

- 320、390、768、1024、1440、1920 六档 CSS 屏宽：根容器无横向溢出，检查到的段落、标题、按钮及公司行无内部文字溢出。
- 桌面与手机截图已目视检查。项目详情打开及关闭正常；资源检查通过：18 项目、55 本地文件、47 锚点、视频范围请求。
- 字号使用 rem 分级，不对页面做整体缩放；没有禁止用户浏览器缩放。本轮未验证屏幕阅读器或浏览器 200% 放大，不宣称完整无障碍合规。
- V3 ZIP 保留为上一版快照；当前源码使用 refinement.css?v=3.1。
