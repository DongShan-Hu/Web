# 客户站点维护

## 独立目录

每个站点在 `public/sites/<slug>/`，`slug` 使用小写英文、数字和短横线，例如 `acme-company`。该目录内的首页必须是 `index.html`。公网地址为 `http://acme-company.134.195.211.122.sslip.io/`；自己的域名启用后为 `acme-company.你的域名`。文件目录是内部组织方式，客户访问子域名。

资源按相对路径引用：

```html
<link rel="stylesheet" href="styles.css">
<img src="assets/cover.webp" alt="项目现场">
<video src="media/project.mp4" controls preload="metadata"></video>
```

建议使用相对路径，以便同时通过本地 `/sites/<slug>/` 和公网客户子域名预览。客户子域名下的 `/assets/cover.webp` 会指向该客户自己的根目录，但此路径不能用于主站目录预览。React/Vue/Vite 的静态展示页面可使用相对 base `./`；使用客户端路由的应用应按客户子域名单独配置回退，不能给整个集合添加首页回退。

## 目录登记

在 `public/sites.json` 添加：

```json
{
  "slug": "acme-company",
  "name": "客户公司",
  "category": "company",
  "summary": "业务、团队与项目案例介绍",
  "cover": "sites/acme-company/assets/cover.webp",
  "coverAlt": "客户公司的项目展示封面",
  "tags": ["公司介绍", "项目案例"],
  "updated": "2026-09-14",
  "listed": true
}
```

`category` 允许 `company`、`resume`、`portfolio`、`engineering`；`cover` 可以省略，此时显示文字封面。`updated` 写实际更新日期。`listed: false` 只是不在主站显示，并不会阻止直接访问。

没有客户素材时先在本地用模板制作。添加脚本默认不在主站收录，填完页面后再改为 `true`。已做好的网站直接复制并登记，不必使用模板。

## 发布检查

```sh
npm run check
npm run dev
```

电脑与手机视口检查排版、导航、作品图集、视频与下载。客户站点页面不要引用模板中的待填写内容。通过后提交代码，按服务器部署文档更新。

GitHub 限制单文件大小；检查器会拒绝 100 MB 或以上的文件。客户视频增多后可改为对象存储/CDN，页面保留对应 URL，避免仓库长期积累大型视频。

当前版本已收录张红简历与作品集，目录为 `public/sites/zhang-hong/`，文字简历为 `resume.html`，下载文件为 `zhang-hong-resume.pdf`。网页简历与独立 PDF 需要分别更新。添加其他客户前确认哪些素材和联系方式可以公开，随后复制到客户目录并登记。
